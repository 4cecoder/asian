# Sub-Domain 3: Phoneme Extraction & Grapheme-to-Phoneme (G2P) Engine

Converts transcribed text into phonetic representations, one dedicated
sub-module per target language (Mandarin, Japanese, Thai, Vietnamese,
Korean), unified behind a single facade. This is the reference side of
pronunciation scoring: it produces the phoneme sequence the user's actual
speech gets compared against.
